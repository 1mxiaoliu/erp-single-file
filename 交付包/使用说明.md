# 进销存 ERP · 使用说明书

一个不用安装、不用注册、不用联网、不花钱的进销存工具。  
所有数据都存在**你自己的设备上**，不会传到任何服务器，也没有账号和年费。

---

## 一、怎么打开

**电脑（最简单）**  
双击 `进销存ERP.html` 就行。建议用 **Chrome** 或 **Edge** 打开。  
（如果双击后是用记事本或别的软件打开的，右键 →「打开方式」→ 选 Chrome / Edge。）

**手机上**  
把这个文件传到手机，用系统浏览器打开；或者用「多设备版」那套（见第九节）。  
手机上可以点浏览器菜单里的「**添加到主屏幕**」，用起来跟 App 一样。

> ⚠️ 三个必须知道的限制
>
> 1. **不要用微信/QQ 的聊天窗口直接点开**。那种内置浏览器打不了印，数据也容易被清掉。要「用默认浏览器打开」。
> 2. **不要用无痕/隐私模式**。关掉窗口数据就没了。
> 3. **数据存在哪个浏览器里，就只在哪个浏览器里**。换浏览器、换电脑都看不到 —— 除非导出再导入（见第八节）。

## 二、第一次用，先做这三件事

### 1. 填自己的公司信息

**我的 → 公司信息 / LOGO**

填公司名、电话、地址、开户行和账号，传一张 LOGO 图片。  
这些会印在送货单抬头上，**LOGO 和公司名一起居中排**。**LOGO 建议用白底黑字或纯色**，打印出来清楚（系统会自动转成黑白）。

「送货人」这一项留空的话，单子右下角会留一条空白横线，可以现场手签名字；填了就直接印上去。

### 2. 建商品

**商品 → 新增商品**

必填的是名称和单位；建议把**进货价、销售价**一起填好，开单时会自动带出来。  
可以给商品拍照（点商品图片），打印和查找时能认出来。

### 3. 建往来单位

**我的 → 往来单位**

分「供应商」和「客户」两类，先把常打交道的建好。  
开单时直接选，不用每次手打名字，**同一个客户下次还会自动带出上次的价格**。

---

## 三、日常开单

**进货** → 「新建进货单」  
**销售** → 「新建销售单」

单据里这样操作：

| 想做的事       | 怎么做                            |
| ---------- | ------------------------------ |
| 加一个商品      | 上面搜索框输名字或编码，点出来就加到明细           |
| 建一个还没录过的商品 | 搜索框右边「＋ 新建商品」，当场填名字和价格，保存后直接进单 |
| 改这一单的价格    | 明细行里那个 `单价 ¥__` 直接改，本单金额跟着变    |
| 同一个商品两个价   | 明细行右边的 `＋` ，会复制一行，价格单独改        |
| 改数量        | 点 `−` `＋`，或者直接点数字改             |
| 删一行        | 行尾的垃圾桶图标                       |

**关于价格，记住一条规则**：你在单据里改的价格，**只影响这一单**，不会改动商品档案里的价格。  
但系统会记住"这个客户上次是多少钱"，下次选同一个客户自动带出来。所以同一个货卖给 A 店 15、卖给 B 店 20，不会互相干扰。

保存后，单据会出现在列表里，随时可以点开改。

## 四、打送货单

**发票** → 点一张单据 → 「打印 / 导出 PDF」

### 纸张怎么设（这一步不对就会印歪，甚至整张竖过来）

系统里可以选两种纸，在「我的 → 公司信息 / LOGO → 打印纸张」里切：

| 系统里选的纸型 | 什么时候用 | 打印对话框怎么设 |
|---|---|---|
| **A4 横向**（默认） | 普通 A4 纸 | 纸张选 **A4**；布局 / 方向选**横向**；缩放 100% |
| **241×139.5mm 三联单** | 241×279mm 三联二等分针式纸 | 纸张选同名自定义纸（列表里没有就在「打印机属性 → 纸张/质量 → 新建」加一个）；缩放 100% |

两种纸随时可以换，不用每次都进设置：开单据时点预览上方那行「纸张 **A4 横向**」，点一下就在两者之间切换。

**印出来整张是竖的、字要歪着头看**，就是系统里的纸型和打印机里装的纸对不上——打印机找不到那个纸型会退回 A4 纵向，241mm 宽的内容塞不进 210mm，驱动就把整张转了 90°。把系统里的纸型和打印对话框里的纸张改成一致即可。

**边距**选「无」或「最小」；**缩放 100%**，不要勾「适应页面」。

### 微信里打不出来

微信内置浏览器不支持调用打印，右上角「···」→「在浏览器打开」，再用系统打印。

### 只想存个 PDF 发人

打印对话框里「目标打印机」选 **另存为 PDF** 就行。

## 五、库存和报表

**库存** 里有四块：库存查询、出入库流水、库存盘点、库存调拨。  
进货和销售会自动加减库存，不用手动记。

**报表** 里有经营概况（销售额、进货额、库存总值）和近 6 个月趋势。

### 给客户发对账单

**报表 → 客户对账单**，先选时间段：

- 两个日期框直接填起止日期，想对哪一段就对哪一段（跨月也行）
- 懒得填就点上面的快捷项：**本月 / 上月 / 近 30 天 / 今年 / 全部**
- 起止填反了会自动对调；选完下面立刻列出这段时间有过单的客户和金额

然后：

- 点某个客户那一行的「下载」→ 只出这一家
- 点「生成全部客户的账单」→ 有单的客户各出一份，连续下载

文件直接进手机的「下载」或电脑的「下载」文件夹，**账本里不会保存任何表格文件**，也不用装 Excel。

生成出来的表是：

| 时间    | 物品名称 | 物品单位 | 物品数量 | 单价  | 金额  | 备注  |
| ----- | ---- | ---- | ---- | --- | --- | --- |
| 10月3日 | 洗洁精  | 斤    | 200  | 0.6 | 120 | 一店   |

第一行是标题，最后一行是「合计：XXXX元」，日期相同的连续几行只在第一行写日期 —— 和常见的手工对账单一致。

**标题抬头取的是公司名**，在「我的 → 公司信息 / LOGO → 公司名称」里填；客户名则体现在文件名上。两处都跟着你自己录的资料变，不需要改代码。

数据全部来自这个客户在**所选区间内**的销售单；**备注**取销售单上填的备注（比如送到哪家门店）。

文件名分两种：

- 刚好选满一个整月 → `客户名10月份对账明细.xlsx`（和以前一样）
- 自定义区间 → `客户名2026-10-05至2026-10-20对账明细.xlsx`

## 六、备份 —— 这一条最重要

**我的 → 备份恢复 → 导出**，会下载一个 `.json` 文件。

这个文件里就是你的全部账目（商品、单据、客户、公司信息）。建议：

- **每个月导一次**，存到网盘 / 微信收藏 / U 盘
- **换电脑、换浏览器、清理浏览器缓存之前，必须先导出**
- 重装系统前更不用说

恢复的时候：同一位置 → **导入**，选那个 json 文件。

> 系统自己也会在浏览器里留一份「上一版」快照，但那只防误操作，**不防浏览器被清理**。别指望它。

## 七、东西存哪儿了，什么情况会丢

存在**浏览器自己的存储空间**里（不是文件、不是云盘）。所以下面这些操作会丢数据：

- 清理浏览器的「缓存 / 网站数据 / Cookie」
- 用无痕模式
- 换一个浏览器或用另一台电脑打开
- 手机「清理垃圾」把浏览器数据清了

正常使用不会丢。想彻底放心，就按第六节定期导出，或者用「多设备版」把数据放到自己的 NAS 上。

---

## 八、电脑和手机想共用一份数据

两条路：

**A. 数据放自己的飞牛 NAS（推荐，需要飞牛常年开机）**

见 `多设备版-飞牛/部署说明.md`，做 3 件事就能用：

1. 文件夹拖上 NAS，改密码
2. 建一个 Docker 项目（点两下）
3. 照 `Tailscale-外网访问.md` 装一次 Tailscale，手机出门也能连

做完之后手机、电脑共用一份数据，人在外面用 4G 也能开单，数据存在自己硬盘上。  
**电脑随便关，只有 NAS 需要一直通电。**

**B. 没有 NAS**  
那就在一台设备上录，需要时「导出 → 传到另一台 → 导入」。  
不方便，但 0 成本、不会出错。

> 如果只用单文件版，「关于存储」里的「**设置云同步**」和「**用自己的 NAS 服务器**」两个按钮**不用管**，它们是给多设备版用的，留着不影响任何功能。  
> 其中「用自己的 NAS 服务器」在多设备版里点一下，等于把本机账目整体上传到飞牛（只在页面是 `http://飞牛IP:8080` 打开时才有意义）。

## 九、常见问题

**改的数字存不住 / 一刷新就变回原样**  
确认不是无痕模式；确认不是用微信内置浏览器打开的。

**提示「本地空间已满」**  
图片太多把浏览器存储占满了。**我的 → 关于存储** → 点「压缩全部图片」，或「清掉自动快照」。

**打印出来是白纸**  
用 Chrome/Edge 打开再打；微信里打不了。

**打出来整张是竖的 / 位置偏上偏下**  
系统里的「打印纸张」和打印对话框里选的纸张不是同一个。用 A4 纸就两边都选 A4 横向；用三联单就两边都选 241×279。缩放保持 100%。

**换了电脑，数据没了**  
数据不会跟着文件走。在原电脑上「导出」，在新电脑上「导入」。

**不小心点错，单据被删了**  
**我的 → 备份恢复**里可能有「上一版」，能恢复；所以定期导出才是根本。

**多台设备同时开单，单号会重复吗**  
有可能（同一秒开单）。建议开单集中在收银那一台。

## 十、几个省事的小地方

- 商品可以**拍照**，列表里直接看图认货
- 单据里**没建过的商品可以当场建**，不用先退出去录商品
- 明细行 `＋` 可以给同一个商品加第二行（不同价、不同备注）
- 单据抬头、联系方式、银行账号都在「公司信息」里改，改一次全部单据同步生效
