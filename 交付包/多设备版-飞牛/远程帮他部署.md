# 远程帮别人装（不用上门）

> 场景：飞牛 NAS 在客户店里/家里，你在自己电脑上，把整套装好、验证通过、交接清楚。
> 全程约 **30～40 分钟**，客户只需要做两件事：装一个远控软件、在他电脑上坐着。

---

## 一、三条路，先选一条

| 方式 | 客户要做什么 | 你能操作到什么 | 适合 |
|---|---|---|---|
| **① ToDesk / 向日葵远控**（推荐） | 装个软件，念一串设备码 | 他的整台电脑，等于你坐在他旁边 | **99% 的情况**，客户零技术门槛 |
| ② 飞牛自带远程访问（FN Connect） | 后台开启 FN Connect，给你 FN ID + 一个子账号 | 飞牛整个网页后台（文件、Docker、日志都在里面），**足够装完** | 客户不肯装远控，见第四节 |
| ③ SSH | 飞牛设置里开 SSH，给你账号密码 | 命令行，最快最稳 | 你自己熟 Linux，客户肯配合 |

**默认走 ①**，因为后面传文件、看日志、改 compose 全在图形界面里，不用教客户敲命令。
**客户不肯装远控就走 ②**，飞牛后台已经够用了，代价是你要适应 2 Mbps 的中继速度。

---

## 二、开工前：让客户准备好这 5 样

直接把这 5 条复制发给他（微信）：

> 麻烦你帮我确认几件事，我远程帮你弄，大概半小时：
>
> 1. 电脑上装个 **ToDesk**（https://www.todesk.com ），装完把**设备代码**和**临时密码**发我
> 2. 电脑和 NAS 在**同一个 WiFi / 同一个路由器**下吗？
> 3. 飞牛后台能打开吗？打开后左上角显示的**地址**是什么（像 `192.168.1.20:5666`）
> 4. 飞牛里的 **Docker** 应用装了吗？（后台 → 应用中心，搜 Docker）
> 5. 你有没有 **Tailscale 账号**？（没有就等会儿我帮你注册，免费）

同时你自己准备好：

- `进销存ERP-交付包.zip`（通过微信发给客户，或者等下用 ToDesk 的文件传输直接推过去）
- 客户的**账本密码**约定一个（别用 123456，8 位以上）

## 三、30 分钟操作流程

### 第 1 步（3 分钟）连上他的电脑

ToDesk 输设备码 + 密码 → 连上。先确认两件事：

- 他的浏览器能打开 `http://192.168.x.x:5666`（飞牛后台）
- 看飞牛后台首页的**存储空间**名字，是 `vol1` 还是别的（后面路径要用）

### 第 2 步（5 分钟）把文件放上 NAS

**用 ToDesk 的文件传输**把 `进销存ERP-交付包.zip` 推到他电脑桌面，然后：

1. 飞牛后台 → **文件** → 左侧切到**管理员视角**
2. 进 `vol1` → `1000`（1000 是他的用户编号，不确定就挨个点开看）→ 新建文件夹 `erp`
3. 把桌面那个 zip 拖进去 → 右键**解压** → 删掉 zip
4. 确认结构（**少一层、多一层都起不来**）：

```
/vol1/1000/erp/
    └── 多设备版-飞牛/
        ├── docker-compose.yml
        ├── server.js
        └── web/进销存ERP.html
```

> 飞牛的文件管理器有时拖不进去文件夹，就**先上传 zip 再解压**，最稳。

### 第 3 步（5 分钟）改配置

飞牛「文件」里右键 `docker-compose.yml` → **用文本编辑器打开**，改两处：

```yaml
      ERP_PASS: "换成约定好的密码"
```
```yaml
      TS_AUTHKEY: "tskey-auth-粘贴客户的钥匙"
```

**Tailscale 钥匙怎么来（重要，见下面第五节）**：必须用**客户自己的账号**生成。所以这一步通常要：

1. 现场用客户邮箱注册 Tailscale（或让他自己注册，你在旁边看着）
2. 后台 → Settings → Keys → Generate auth key → 勾 **Reusable** → 复制
3. 粘贴进 compose

### 第 4 步（5 分钟）建项目启动

飞牛 → **Docker** → **Compose** → **新增项目**：

| 栏位 | 填 |
|---|---|
| 项目名称 | `erp` |
| 文件夹路径 | `/vol1/1000/erp/多设备版-飞牛` |
| 配置文件 | 选「使用现有的 docker-compose 配置」 |
| 立即启动 | 勾上 |

点完成，等镜像下载（第一次要下 node + tailscale 两个，国内可能 3～10 分钟）。

> 客户网络慢就提前说一句："正在下载安装包，可能等几分钟。"

### 第 5 步（5 分钟）验证，四件事都要过

| # | 验证什么 | 怎么验 | 不通过怎么办 |
|---|---|---|---|
| 1 | 内网能开 | 浏览器 `http://飞牛IP:8080` → 出登录页 → 输密码进去 | 看 `erp` 容器日志有没有 `已启动·端口8080` |
| 2 | 能存能读 | 随便改个公司名，刷新还在 | 看日志有没有 `保存成功 ver=1` |
| 3 | Tailscale 上线 | tailscale.com 后台 Machines 里出现 `feiniu-erp`，状态 Connected | 看 `tailscale-erp` 日志，多半是 key 没改 |
| 4 | 外网能开 | **让客户手机关 WiFi 用 4G**，装 Tailscale 登录同一账号，访问 `http://feiniu-erp:8080` | 见第 6 节排查 |

**第 4 条一定要当场验。** 客户回家才发现外网打不开，你又得再来一次。

### 第 6 步（3 分钟）交接

把下面这张表填好，**截图发给客户**，也自己留一份：

```
账本地址（店里）：http://192.168.x.x:8080
账本地址（外面）：http://feiniu-erp:8080
账本密码：__________
Tailscale 账号：__________（手机号/邮箱）
飞牛 NAS 位置：/vol1/1000/erp/多设备版-飞牛
数据文件：data/db.json（每日备份在 data/bk/）
```

再带客户做两件事：

1. 手机浏览器打开账本 → **添加到主屏幕**（iPhone 必须用 Safari）
2. 教他 **我的 → 备份恢复 → 导出**，每月点一次

## 四、用飞牛自带远程访问来配（方案 ②，客户不装任何软件）

### 先说结论：这条能用来"配"，不能用来"日常用"

| 用途 | 走得通吗 | 原因 |
|---|---|---|
| **你远程登录他飞牛后台，建目录、传文件、建 Docker 项目、改 yml** | ✅ 完全够 | 这些全在 5666 后台页面里 |
| **客户在外面打开账本（8080）** | ⚠️ 能，但很别扭 | 见下面第三节，别指望它 |

所以正确组合是：**配置阶段用 FN Connect，日常访问仍然用 Tailscale**（compose 里已经带上了，不冲突，可以同时存在）。

---

### 第一步：让客户开通 FN Connect（3 分钟）

客户操作，或者你在电话里指路：

1. 飞牛后台 → **系统设置** → **远程访问**（或直接点 **FN Connect**）
2. 需要先注册并登录**飞牛云端账号**（手机号/邮箱，免费），绑定后得到一个 **FN ID**（比如 `jonyle`）
3. 开启服务，页面会给出访问链接，形如：

```
https://你的ID.5ddd.com          ← 中继访问（免费版）
```

> 免费版（FN 权益·基础版）：**中继带宽 2 Mbps、流量不限**。管理后台够用。
> 想要更快就升级带宽，但这个场景**不建议花钱**——配置是一次性的。

4. 把 **FN ID + 飞牛账号密码**（或下面说的子账号）给你

### 第二步：别要主密码，让他给你建个子账号（推荐）

直接拿客户管理员主密码，出问题说不清。让他这样做：

1. 飞牛后台 → **用户管理** → 新建用户，比如 `installer`
2. 权限选**管理员**（要装 Docker，普通用户不行）
3. 把这个子账号的密码给你

装完让他**把这个账号停用或删掉**。这样双方都干净，也免得你手机里存着别人的主密码。

### 第三步：你登进去操作（和远控几乎一样）

浏览器打开 `https://他的ID.5ddd.com` → 用子账号登录。接下来的操作和第三节完全一样，四个区别：

| 差别 | 说明 |
|---|---|
| **传文件更简单了** | 用**你自己的浏览器**操作他的后台，上传时选的是**你电脑上的 zip**，不用绕 |
| **文本编辑器能用** | 文件管理器里右键 `docker-compose.yml` → 用文本编辑器打开，直接在网页里改 |
| **Docker 面板能用** | Compose → 新增项目，路径填 `/vol1/1000/erp/多设备版-飞牛` |
| **看日志能用** | 容器 → 日志，排查全在网页里 |

⚠️ **2 Mbps 中继上传大文件会慢**。zip 只有 170KB，没问题；但拉 Docker 镜像是在 NAS 本地下载的，不走中继，所以不会卡。

⚠️ 中继有时会断。改完一处就点保存，别开着页面去泡茶。

### 第四步：验证（这一步必须让客户配合）

你在中继上能做的前三件事都能验：

1. ✅ 内网能开 —— 让客户在他电脑上打开 `http://飞牛IP:8080`
2. ✅ 能存能读 —— 让他改个公司名，刷新还在
3. ✅ Tailscale 上线 —— 你直接看 tailscale.com 后台有没有 `feiniu-erp`

**第 4 条「手机关 WiFi 用 4G 能打开」必须客户配合**，因为他手机要装 Tailscale 登录。打电话指路，或者发截图。

---

### 关于"用 FN Connect 直接开账本"——为什么劝你别这么设计

飞牛从 **V0.9.27** 起，FN Connect 支持访问第三方应用和 Docker 容器，地址形如：

```
https://容器ID.他的ID.5ddd.com
```

听起来正好能替代 Tailscale，但有三个坑：

| 坑 | 后果 |
|---|---|
| **必须先登录飞牛管理页**，再从 Docker 面板点容器旁的 🔗 图标才能打开 | 客户每次开单要登两次（飞牛 + 账本），体验很差 |
| **链接用容器 ID 生成**，容器重建/换镜像后链接就变 | 客户存的收藏夹会失效，又来找你 |
| **官方中继对非 5666 端口不转发**（老版本尤其是这样），基础版只有 2 Mbps | 时快时慢，图片多的单据会转圈 |

Tailscale 没有这三个问题：地址固定（`http://feiniu-erp:8080`）、一点就开、直连不走中继（速度是你家宽带上行）。

**结论**：FN Connect 当"你的施工通道"，Tailscale 当"客户的日常通道"。两个都开着，互不影响。

> 如果客户连 Tailscale 都不想装，那唯一干净的办法是 **cloudflared 命名隧道 + 一个域名**（约 ¥60/年），给个固定网址，谁打开都能用。需要就告诉我，配置我给。

---

⚠️ FN Connect 地址是暴露在公网的入口，提醒客户：**别把 `https://ID.5ddd.com` 发群里**，也别设弱密码——这个后台能装 Docker，等于整台 NAS 的控制权。

## 五、最容易踩的坑：Tailscale 账号到底是谁的

| 做法 | 后果 |
|---|---|
| ❌ 用**你自己的** Tailscale 账号 | 客户以后加新手机、换设备、查 IP，全得找你。你成了永久客服 |
| ✅ 用**客户自己的**账号 | 你只是帮他配一次，之后他自己能管 |

**正确做法**：现场用客户的手机号/邮箱注册，你代他操作登录，注册完让他**自己记下账号密码**（写进交接表）。

如果客户暂时不想注册，也可以：先用你的账号跑通验证，**当天之内**再迁到他账号（删掉设备 → 用他的 key 重新起容器，`ts-state` 目录删掉重来）。别拖，拖着就变成你的长期负担。

## 六、远程时常见的 5 个卡点

**① `erp` 容器起不来，日志 `Cannot find module '/src/server.js'`**
目录层级错了。`docker-compose.yml` 必须和 `server.js` 同一层，重新摆好 → 停止 → **清除** → 启动。

**② 日志 `[致命] 数据目录不可写`**
飞牛上这个目录的权限问题。在文件管理器里把 `erp` 文件夹的**所有者**改成管理员账号，或 `chmod -R 777 /vol1/1000/erp`（临时手段，装完可以收回来）。

**③ 8080 被占用**
飞牛自己的应用可能占了。compose 里改成 `"8090:8080"`，记得**同时告诉客户**外面访问要加 `:8090`。

**④ Tailscale 容器一直重启**
- 缺 `/dev/net/tun`：飞牛内核一般支持，报这个错就是 Docker 版本太旧，升级 Docker 应用
- `TS_AUTHKEY` 还是占位符：日志会出现 `invalid key`

**⑤ 镜像下载卡住不动**
飞牛 Docker → 设置 → **镜像加速**，填阿里云/腾讯云的加速地址（客户自己账号申请，免费）。填完重新部署。

## 七、装完之后，你还欠客户什么

交付不是"能打开"就完了。主动说清这三件事，能省掉 80% 的后续来电：

1. **NAS 必须一直通电。** 关机时手机打不开，但已开的单不会丢，来电自动补传。
2. **每月导出一次备份。** 我的 → 备份恢复 → 导出，存到电脑上。这是硬盘坏掉时的唯一保险。
3. **不要两个人同时改同一张单。** 极少情况会以服务器那份为准。
