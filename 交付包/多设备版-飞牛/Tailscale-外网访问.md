# Tailscale 外网访问 · 一步一步来

> 目标：**手机在任何网络（4G、别人店里 WiFi、外地）都能打开你自己的账本**，而且不花一分钱、不把账本暴露在公网。

读完大概 8 分钟，操作 15 分钟。做完一次，以后不用再动。

---

## 先说清楚它在干什么

| 方案 | 原理 | 风险 |
|---|---|---|
| 路由器端口转发 | 把 NAS 的 8080 直接捅到公网 | ❌ 全世界的扫描器都会来敲门，密码是唯一防线 |
| 公网临时隧道 | 一个随机网址指向 NAS | ⚠️ 网址乱、会变、谁拿到都能试密码 |
| **Tailscale** | 给每台设备装一块"虚拟网卡"，组成只有你能进的私有网络 | ✅ 别人根本看不到你的 NAS |

类比：端口转发 = 把仓库大门开在马路边上，只靠一把锁；
Tailscale = 仓库藏起来，只有你和你家人的钥匙能进，门口连路都没有。

它免费版给 **3 个用户、100 台设备**，个人用绰绰有余。

---

## 第 1 步：注册 Tailscale 账号（3 分钟）

1. 电脑浏览器打开 **https://tailscale.com**
2. 右上角 **Get started** / **Sign in**
3. 选一个登录方式（三个都行，不需要信用卡）：

   | 方式 | 适合 |
   |---|---|
   | **Google 账号** | 最省事，有 Gmail 就用这个 |
   | **Microsoft 账号** | 有 Outlook / Hotmail |
   | **GitHub** | 有一点技术背景 |

   > 用邮箱注册也可以，会给你发验证链接。
   > ⚠️ **记牢你选的这个账号**：手机、电脑、NAS 必须全部登录**同一个账号**，否则互相看不见。

4. 登录后进入后台（admin console），左边能看到 **Machines**（设备）列表，现在是空的。

---

## 第 2 步：生成一把"钥匙"，让 NAS 自动登录（2 分钟）

NAS 没有浏览器，所以要提前给它生成一把授权钥匙。

1. 后台左侧点 **Settings**（设置）→ 找到 **Keys**（或 **Auth keys**）
2. 点 **Generate auth key…**
3. 弹窗里这样设：

   | 选项 | 选什么 | 为什么 |
   |---|---|---|
   | Description | `feiniu-erp` | 以后知道这把钥匙给谁用的 |
   | Reusable | **勾上** | 容器重建后不用重新生成 |
   | Ephemeral | **不勾** | 勾了容器一停设备就消失 |
   | Expiration | **90 days**（或 Never） | 见下面说明 |

4. 点 **Generate key**，复制那串 `tskey-auth-xxxxxxxxxxxx`

> **关于 90 天过期**：钥匙过期**不影响已经登录的 NAS**，只在"新增设备"时才需要新钥匙。
> 也就是说：90 天后你的手机电脑照常能用，只有当你要再加一台新手机时，回来重新生成一把即可。
> 想彻底省事就选 **Never**（永不过期），代价是这把钥匙泄露后风险更高——而它只会出现在你自己 NAS 的配置文件里。

---

## 第 3 步：填进配置文件，启动（3 分钟）

打开 `docker-compose.yml`，找到这两行，改掉：

```yaml
      ERP_PASS: "change-me-123"                     # ← 改成你的账本密码
```

```yaml
      TS_AUTHKEY: "tskey-auth-在这里粘贴"            # ← 粘贴第 2 步那串
```

保存，然后按飞牛的顺序让它生效：

> **飞牛的 Compose 面板不会自动重载配置**，必须：
> 项目上点 **停止** → 确认改动已保存 → 点 **清除** → 再点 **启动**

> 第一次启动会下载两个镜像（node 约 50MB，tailscale 约 40MB）。国内可能慢，飞牛 Docker 设置里填个镜像加速地址会快很多。

---

## 第 4 步：检查 NAS 是不是真的上线了（1 分钟）

**看容器日志**：点 `tailscale-erp` 容器 → 日志，看到类似这几行就对了：

```
magicsock: home is now derp-xxx
tsnet: state storage ...
Health check: ...
```

更直观的办法：**回到 tailscale.com 后台看 Machines 列表**，应该多出一台：

| 名字 | IP | 状态 |
|---|---|---|
| `feiniu-erp` | `100.x.x.x` | ● Connected |

**看到 `100.` 开头的地址，说明 NAS 已经进了你的私有网络。**
就是这个地址，记下来（一般形如 `100.101.102.103`）。

> 显示 `Offline` 的话：容器没启动 / 钥匙填错 / NAS 上不了外网。先看日志。

---

## 第 5 步：手机和电脑装 App（5 分钟）

| 设备 | 怎么装 |
|---|---|
| **iPhone** | App Store 搜 **Tailscale** → 装 → 打开 → Sign in，用第 1 步那个账号 |
| **安卓** | 应用商店搜 Tailscale；搜不到就去 **https://tailscale.com/download/android** 下 APK |
| **Windows / Mac** | **https://tailscale.com/download** → 装完右下角托盘图标 → Log in |

装完打开 App，第一件事是**登录同一个账号**，然后点一下那个开关（iOS 上是 VPN 开关，安卓是 Connect 按钮），状态变成 **Connected**。

> 手机会弹「Tailscale 想要添加 VPN 配置」——点**允许**。这不是翻墙软件，它只是建立到你自己 NAS 的加密通道。

---

## 第 6 步：打开你的账本

手机浏览器（Safari / Chrome，**不要用微信打开**）输入：

```
http://100.x.x.x:8080
```

把 `100.x.x.x` 换成第 4 步看到的那个地址。会先出现登录页，输入 `ERP_PASS` 那个密码。

进去后右上角显示 **已自动保存 · 已同步** 就成了。

**更好的地址**（开启 MagicDNS 后可用，比记 IP 舒服）：

```
http://feiniu-erp:8080
```

> `feiniu-erp` 这个名字来自 compose 里的 `TS_HOSTNAME`，想改就改那一行。

### 顺便把它变成 App 图标

- **iPhone**：Safari 打开 → 底部「分享」→ 向下找「**添加到主屏幕**」
- **安卓**：Chrome 打开 → 右上角 ⋮ → 「**安装应用**」/「添加到主屏幕」

装完是一个独立图标，打开全屏、没有地址栏，跟真的 App 一样。断网也能打开界面看单据，改动会自动排队，联网后补传。

## 每天到底怎么用（真实场景）

| 场景 | 需要做什么 |
|---|---|
| 在店里，手机连店里 WiFi | 直接开图标；Tailscale 开着也行，它自己走内网直连，很快 |
| 出门在外，用 4G | 先确认 Tailscale 开关是开的（一般一直开着就行），然后开图标 |
| 电脑在家里 | 装一次 Tailscale 并登录，之后一直开着，用 `http://feiniu-erp:8080` |
| 完全没网（地下车库、飞机） | 照常开单，右上角显示「未同步」，回到有网的地方自动补传 |

**Tailscale 建议常开**，它耗电极低（安卓上会常驻一个 VPN 通知，属正常）。关掉的话，在外面就打不开 NAS 了。

## 常见问题

**① 应用商店搜不到 Tailscale**

中国大陆区 App Store 有时搜不到。按顺序试：

1. App Store 里把搜索词换成 `tailscale vpn`，或直接打开 **https://apps.apple.com/app/id1475387142**
2. 安卓：**https://tailscale.com/download/android** 下 APK 直接装（需要允许"安装未知来源应用"）
3. 实在装不上 → 用**兜底方案**（见文末），改用浏览器直接访问的隧道方案

**② 后台 Machines 里 NAS 显示 Offline**

按顺序查：
- `tailscale-erp` 容器是不是**运行中**（飞牛 Docker → 容器）
- compose 里的 `TS_AUTHKEY` 是不是还留着占位符 `tskey-auth-在这里粘贴`
- 日志里出现 `invalid key` / `authkey expired` → 回第 2 步重新生成一把，改完记得「停止 → 清除 → 启动」
- NAS 本身能不能上外网（飞牛后台看能不能检查更新）

**③ 手机显示 Connected，但 `100.x.x.x:8080` 打不开**

- 手机和 NAS 是不是**同一个 Tailscale 账号**？（最常见的错）
- `erp` 容器是不是在跑？先在内网用 `http://NAS内网IP:8080` 验证一次
- 地址写的是 `http://` 不是 `https://`（Tailscale 默认不开 HTTPS，写成 https 会连不上）
- 端口是不是改过？如果 compose 里改成了 `8090:8080`，那外面就是 `100.x.x.x:8090`
- 手机上的 Tailscale 开关是不是真的开着（iOS 看设置里 VPN 是否已连接）

**④ 速度慢**

Tailscale 会先尝试"打洞"直连，成功时速度就是你家宽带的上行速度，很快。
如果两端网络太严格（对称 NAT）打不通，会走国外的中继服务器，那就慢了。

想强制直连更稳：在 tailscale.com 后台 → **DNS** 页面 → 打开 **MagicDNS**；
再到 **Settings → Keys** 之外找 **ACL / 中继** 相关设置可以指定自建 DERP 节点（进阶，不做也基本够用）。

**⑤ 会不会把我的数据传给别人**

不会。数据只存在 NAS 硬盘上（`data/db.json`）。Tailscale 只负责"把网络接通"，看不到内容——流量是端到端加密的。

**⑥ 以后换了手机 / 加一台平板**

新设备装 App、登录同一账号，就直接能用，不用改 NAS 任何配置。

**⑦ 我把 NAS 换到别的网络了**

不用改任何东西。Tailscale 地址跟着设备走，不跟着 IP 走——这也是它比端口转发省心的地方。

## 兜底方案（Tailscale 实在用不了时）

按推荐顺序：

| 方案 | 优点 | 代价 |
|---|---|---|
| **飞牛自带远程访问** | 不用装任何 App | 要确认它把 8080 也转出来了，可能只转后台页面 |
| **cloudflared 命名隧道** | 给一个固定网址，谁都能打开，最适合交付给客户 | 需要一个域名（约 ¥60/年），Cloudflare 免费 |
| **临时隧道** | 0 成本，5 分钟能用 | 网址每次重启都变，只适合演示 |

需要哪种告诉我，配置我来给。

## 最后一句安全提醒

Tailscale 保护的是"谁能连进来"。但**账本本身还有一道密码**（`ERP_PASS`），别设成 `123456`。
两道防线都留着，比只靠一道强得多。
