# 进销存 ERP · 飞牛 NAS 部署说明

这套东西让**手机、电脑、平板共用同一份账目**，数据存在你自己飞牛的硬盘上，不花钱、不经任何第三方。

**开始前确认三件事：**

1. 飞牛已经装好并能在浏览器打开后台（例如 `http://192.168.1.100:5666`）
2. 飞牛的应用中心里装了 **Docker**（没装就点一下装，官方免费应用）
3. 飞牛**常年开机**（关机时手机上打不开，这是唯一的硬性要求）
4. 有一个 **Tailscale 账号**（免费，出门在外就靠它，没有的话第 5 步现场注册 3 分钟）

---

## 文件夹里有什么

| 文件 | 作用 |
|---|---|
| `docker-compose.yml` | 启动配置，**要改两处：账本密码 + Tailscale 钥匙** |
| `Tailscale-外网访问.md` | **出门在外怎么用**（手机 4G、外地 WiFi 都能打开），第一次必须照着做一次 |
| `远程帮他部署.md` | 如果你要**帮别人装**（客户不在身边），看这份，含远程流程和交接清单 |
| `server.js` | 服务端：登录、存取数据、每日备份（Node，零依赖） |
| `web/进销存ERP.html` | 网页本体（以后换新版就覆盖它） |
| `web/manifest.webmanifest`<br>`web/sw.js`<br>`web/icon-*.png` | 让页面能"添加到主屏幕"、断网也能打开，**不要删** |
| `web/icon-180.png` | iPhone 主屏图标 |
| `Dockerfile` | 备用，飞牛里**用不到**，不用管它 |
| `部署说明.md` | 就是这份 |

## 第一步：把文件夹传上飞牛

> **用电脑操作，不要用手机。** 电脑打开飞牛后台网页就能干，不用装软件。

**① 建目录**

飞牛后台 → **文件** → 左侧切到**管理员视角**，进入 `vol1` → `1000`（`1000` 是你的用户编号）→ 新建文件夹 **`erp`**。

最终路径就是 `/vol1/1000/erp/`。

> 别放进 `/vol1/docker`：那是飞牛存 Docker 镜像的地方，系统自己管，别混。

**② 把整个 `多设备版-飞牛` 文件夹拖进 `erp` 里**

浏览器只能一个个选文件、拖不了文件夹时，二选一：
- 在电脑上把它压成 zip → 上传 → 飞牛里右键「解压」→ 删掉 zip
- 或者 Windows 资源管理器地址栏输 `\\飞牛IP` 回车，输飞牛账号密码，直接拖进去（更快）

**最终必须是这个结构**（少一层、多一层都会起不来）：

```
/vol1/1000/erp/
    └── 多设备版-飞牛/
        ├── docker-compose.yml
        ├── server.js
        ├── Tailscale-外网访问.md
        ├── 远程帮他部署.md
        ├── 部署说明.md
        └── web/
            └── 进销存ERP.html
```

`data/`、`ts-state/` 目录**不用建**，容器第一次启动会自动创建。

## 第二步：改密码

飞牛「文件」里右键 `docker-compose.yml` → **用文本编辑器打开**，找到这一行：

```yaml
      ERP_PASS: "change-me-123"
```

把 `change-me-123` 换成你自己的密码（8 位以上，别用 123456），保存。
手机和电脑第一次打开时输一次，之后浏览器会记住。

## 第三步：建项目并启动

飞牛 → **Docker** → 左侧 **Compose** → **新增项目**：

| 这一栏 | 填什么 |
|---|---|
| 项目名称 | `erp` |
| 文件夹路径 | 选 `/vol1/1000/erp/多设备版-飞牛`（放着 `docker-compose.yml` 的那一层） |
| 配置文件 | 选好后会自动提示「使用现有的 docker-compose 配置」，选它 |
| 创建项目后立即启动 | **勾上** |

点**完成**，等 1～2 分钟。第一次要从网上下载两个镜像（node 约 50MB、tailscale 约 40MB）。

启动后项目下会有**两个容器**，都是「运行中」就对了：

| 容器 | 作用 | 停掉会怎样 |
|---|---|---|
| `erp` | 账本本体 | 内网外网都打不开 |
| `tailscale-erp` | 外网通道 | 店里 WiFi 还能用，出门就用不了 |

点 `erp` 容器看**日志**，应该出现：

```
[17:00:00] 云进销存 已启动 · 端口 8080
[17:00:00] 数据目录 /data
[17:00:00] 密码 已设置（10 位）
[17:00:00] 当前版本 0（空库，第一台打开的设备会上传）
```

> 第一次打开 Docker 应用时，飞牛会让你选 Docker 的存储空间。选**固态硬盘**那一块，以后镜像和容器数据放得快点；选哪块都不影响账目，账目在 `/vol1/1000/erp/` 里。
> 这里**不需要构建镜像**，也不需要点「构建」。如果界面让你选 Dockerfile、点了构建还报错，说明选错成旧配置了，用包里这份 `docker-compose.yml` 重来。

## 第四步：打开试试

浏览器访问 `http://飞牛的内网IP:8080`（飞牛后台首页能看到 IP，例如 `192.168.1.100`）。

会先出现一个登录页，输入 `ERP_PASS` 那个密码（就是第二步改的那个），进去后右上角出现 **已自动保存 17:02:11 · 已同步**，就成功了。

登录一次，这台设备 **30 天内不用再输**。换设备、清了浏览器数据才会再问一次。要主动退出：我的 → 关于存储 → 退出登录。

> 密码连续输错 8 次，这个 IP 会被锁 10 分钟。所以别在公开场合反复试，也不要把链接发到群里。

> **一定要在路由器里给飞牛做 IP 绑定**（按 MAC 固定）。飞牛自身是 `5666` 端口、我们的账本是 `8080`，两个别搞混；IP 一变，书签就打不开了。
> 8080 万一被别的应用占了，把 compose 里改成 `"8090:8080"`，重新部署后用 `http://飞牛IP:8090` 访问。

## 关键一步：把旧账目搬进来

**这一步不能省。** 浏览器是按"地址"分开存数据的：`file://` 双击打开的那份，和 `http://192.168.1.100:8080` 这份，是两个互不相通的仓库。

**情况 A：之前是双击 HTML 用单机版的**

1. 在**旧的那台电脑**上双击打开 `进销存ERP.html`
2. 我的 → 备份恢复 → **导出**，得到 `erp-2026xxxx.json`
3. 用 `http://飞牛IP:8080` 打开，输入密码
4. 我的 → 备份恢复 → **导入**，选刚才那个 json
5. 页面自动上传，飞牛容器日志里出现 `保存成功 ver=1`

**情况 B：之前配过 Supabase 云同步**

1. 用 `http://飞牛IP:8080` 打开 → 我的 → 关于存储 → **设置云同步** → 填同一个 Supabase 地址和 key
2. 等它提示「已载入云端数据」
3. 再点 **用自己的 NAS 服务器** → 确认切换
4. 页面刷新后自动上传到飞牛，日志 `保存成功 ver=1`

之后 Supabase 就可以不用了，也可以去后台把项目删掉。

## 其它设备怎么加

手机、平板、第二台电脑：浏览器打开 `http://飞牛IP:8080`，输一次密码即可。
第一次打开会自动拉取服务器上那份数据，不会把自带的演示商品混进去。

**手机上强烈建议「添加到主屏幕」**，加完就是一个独立图标，打开全屏、没有浏览器地址栏，跟装了 App 一样：

- **安卓 / 微信外的浏览器**：打开页面 → 右上角菜单 → 「添加到主屏幕」/「安装应用」
- **iPhone**：必须用 **Safari** 打开 → 底部「分享」→ 往下找「添加到主屏幕」
- **注意**：微信里打开的网页**装不了**，也打印不了，务必点右上角「…」→「在浏览器打开」

装好之后，就算 NAS 断了、人在外面没网，点开图标也能进界面看单据、继续开单，改动会排队等联网后自动补传。

## 出门在外怎么用（手机 4G、外地 WiFi）

内网 `http://飞牛IP:8080` 只在家里/店里有效。出了这个 WiFi 就要靠 **Tailscale**——已经写进 `docker-compose.yml` 了，不用另外装。

**照着 `Tailscale-外网访问.md` 做一次**（约 15 分钟），做完之后：

- 手机在任何网络下访问 `http://feiniu-erp:8080` 或 `http://100.x.x.x:8080`
- 不暴露公网、别人扫不到、不用买域名、不用花钱
- 加一台新设备只是"装 App + 登录同一账号"，NAS 侧不用动

⚠️ **不要把 8080 直接端口转发到公网**。真要那么做，前面必须套 HTTPS，否则密码是明文传输。

> **飞牛自带的「远程访问 / FN Connect」能替代 Tailscale 吗？不能，别被误导。**
> 它是官方中继，**只转发 5666 管理端口**，基础版带宽 2 Mbps。新版虽然支持点开 Docker 应用，但必须**先登录飞牛管理页**再点容器图标才能进账本，而且链接是按容器 ID 生成的——容器一重建，收藏夹就失效。
> 它的正确用途是：**别人帮你远程装的时候，用它进你后台**（见 `远程帮他部署.md`）。日常开单还是用 Tailscale。

> 如果手机在应用商店装不到 Tailscale，`Tailscale-外网访问.md` 末尾有两条兜底方案（飞牛自带远程访问 / cloudflared 固定域名）。

## 它到底怎么同步的（别期待"秒级"）

- **打开页面**：先拉一次最新，有变化就合并后刷新
- **每次保存**：0.7 秒后自动上传，失败会排队，联网后自动补传
- **两台同时开着**：不会实时互推，各自需要"重新打开/刷新"才看到对方的改动（每 15 秒会把没上传成功的补传一次）
- **两台同时改不同单据**：不会互相覆盖 —— 版本冲突时以服务器为准，本机独有的单据会并进去，然后重试
- **断网开单**：照常保存，右上角显示「未同步」，有网了自动补

一句话：**够用，但不是"你改了我屏幕立刻跳"那种实时。**

## 备份（这套方案的真正好处）

| 位置 | 内容 |
|---|---|
| `/vol1/1000/erp/多设备版-飞牛/data/db.json` | 全部账目，一个 JSON 文件 |
| `/vol1/1000/erp/多设备版-飞牛/data/bk/2026-10-30.json` | **每天第一次保存时**自动留一份，保留 14 天 |

再给 `/vol1/1000/erp` 开 **每日快照、保留 7 天**（飞牛「存储管理」→ 对应存储空间 → 快照）。
这样即便哪天程序出问题、或者误操作删掉，也能倒回昨天。

想手工恢复到某天：把 `bk/2026-10-30.json` 复制成 `db.json`，重启容器即可（改名前先备份当前那份）。

## 以后更新网页

`web/` 是挂载进去的，**直接覆盖 `进销存ERP.html`，浏览器刷新就生效**，不用重启、不用重新部署。

## 以后改了 `docker-compose.yml` 怎么让配置生效（飞牛特有）

飞牛的 Compose 面板不会自动重载配置，**必须按这个顺序**：

1. 项目上点**停止**
2. 改 `docker-compose.yml`
3. 点**清除**（不点这步，改的配置不会生效）
4. 再点**启动**

## 常见问题

**打开是「服务已经在跑了」的提示页**
→ `web/` 里没有 `进销存ERP.html`。检查文件名，不能是 `进销存ERP(1).html`。

**容器起不来 / 日志 `Cannot find module '/src/server.js'`**
→ 目录层级错了：`docker-compose.yml` 必须和 `server.js` 在同一层。按第一步的结构重新摆，再「清除 → 启动」。

**日志 `[致命] 数据目录不可写`**
→ `./data` 这个相对目录没解析对。确认文件夹路径选的是 `docker-compose.yml` 那一层。

**一直弹密码 / 提示密码不对**
→ 密码在 `docker-compose.yml` 的 `ERP_PASS`，改完要按上面「停止 → 清除 → 启动」才生效。
→ 想立刻清掉浏览器里存的错误密码：F12 → Application → Local Storage → 删 `erp_sync_pass`。

**右上角一直显示「未同步 / 未连上服务器」**
→ 看容器日志有没有 `保存成功`。没有就是网络或密码问题。
→ 是不是用 `file://` 打开的？那样永远不同步，必须用 `http://飞牛IP:8080`。

**镜像下载很慢 / 拉不下来**
→ 飞牛 Docker 设置里有「镜像仓库 / 加速地址」，填国内加速地址（阿里云、腾讯云都提供，用自己的账号申请），再重新部署。
→ 也可以改用下面附录里那条命令，逻辑完全一样。

**多台设备同时开单会不会撞单号**
→ 会有极小概率。目前单号按时间生成，两台设备在同一秒开单可能重复。
→ 稳妥做法：**开单尽量集中在收银那台**。

**手机上打印不了送货单**
→ 微信内置浏览器不支持打印，点右上角「在浏览器打开」，再用系统打印。

**数据会不会被飞牛系统更新弄丢**
→ 不会，`data/` 在 `/vol1/1000/erp/` 里，是真实目录，不在容器内部。但请务必开目录快照，硬盘坏了是另一回事。

## 附录一：不用 Compose，一条命令跑起来

SSH 登录飞牛后执行（路径和密码换成你自己的）：

```bash
docker run -d --name erp --restart unless-stopped \
  -p 8080:8080 \
  -e TZ=Asia/Shanghai -e ERP_PASS=你的密码 \
  -e DATA_DIR=/data -e WEB_DIR=/src/web \
  -v /vol1/1000/erp/多设备版-飞牛/data:/data \
  -v /vol1/1000/erp/多设备版-飞牛:/src:ro \
  node:20-alpine node /src/server.js
```

## 附录二：以后要挪到别的 NAS 怎么办

如果哪天换机器（或帮别人装），只需换目录路径，配置本身不用改：

| 系统 | 目录 | 建项目的位置 |
|---|---|---|
| 群晖 DSM 7 | `/volume1/docker/erp/` | Container Manager → 项目 → 新增 |
| 威联通 | `/share/Container/erp/` | Container Station → 应用程序（8080 常被系统占用，改 8090） |
| 极空间 / 绿联 | 各自 Docker 目录 | Docker → 项目 |

## 出厂前测试过的

在模拟环境（同样代码、同样接口、同样的环境变量）跑过完整回归：

1. 第一台设备首次打开 → 自动上传，`ver 0 → 1`
2. 第二台设备首次打开 → 只拉取，**版本号不变**（不重复上传）
3. 第二台加一个商品保存 → `ver 2`，状态显示「已同步」
4. 第一台重新打开 → 拉到 `ver 2`，看到新商品
5. 重复打开不再上传
6. 每日备份文件正常生成
7. 静态文件正常、路径穿越请求（`/../../etc/passwd`）返回 404
8. 数据目录不可写时，日志直接报「[致命] 数据目录不可写」并退出，不会反复重启
