# 不用 NAS 的方案对比

> 场景：多台设备共用一份账目，随时随地能开单，设备不用一直开着。
> 前提：这个网页本身已经支持**三种后端**，换方案不用改代码，只在设置里填地址。

---

## 先认清一件事

"多台设备共用一份数据"必须有**一个常在线的落点**。没有 NAS，这个落点只能来自下面四类：

| 落点归谁 | 方案 | 花钱 |
|---|---|---|
| 云厂商（别人维护） | Supabase / Cloudflare | 0 |
| 云主机（你租的） | 腾讯云轻量 / 阿里云 | ¥68～99 / 年 |
| 你自己的一台旧机器 | 旧笔记本 / 迷你主机 / N1 | 0（耗电） |
| 都不选 | 单文件版 + 手工导出导入 | 0 |

**没有第五种。** 所以问题不是"能不能不要服务器"，而是"这台服务器谁出"。

---

## 方案 A：Supabase 免费云（0 元）

> **已选定这条，具体操作看 `Supabase-开通指南.md`。** 下面是它的原理和取舍。

### 是什么

一个国外的免费数据库服务，你的网页直接连它的 API 读写数据。代码里"设置云同步"那个按钮就是连它。

### 怎么搭（约 20 分钟，详见 `Supabase-开通指南.md`）

1. `supabase.com` 注册（GitHub 账号登录最快）
2. 新建项目，区域选 **Singapore**（离国内最近）
3. SQL Editor 里跑 `Supabase建表.sql`
4. 抄下 **Project URL** 和 **anon / publishable key**
5. **网页要另外托管**：Supabase 的 Storage 禁止托管 HTML（打开只会看到代码），所以用 **Cloudflare Pages** 把 `erp-web` 文件夹拖上去，得到一个 `https://xxx.pages.dev`
6. 打开那个网址 → 我的 → 关于存储 → 设置云同步 → 填第 4 步的两个值

所以严格说是「Supabase 存数据 + Cloudflare 放网页」两个免费账号，各 5 分钟。

### 免费额度（官方，2026 年 2 月）

| 项目 | 额度 |
|---|---|
| 数据库 | 500 MB |
| 出口流量 | 5 GB / 月 |
| API 请求 | 不限 |
| 活跃项目数 | 2 个 |

进销存的数据是纯 JSON，一个月的单子通常几十 KB。**500 MB 够用好几年**——除非你把照片也同步上去。

### 优点

- 一分钱不花，不用买设备、不用装任何 App
- 手机电脑浏览器直接开，跟用网站一样
- 不依赖任何一台自己的机器，电脑手机全关着也能存

### 缺点（必须知道）

| 问题 | 影响 | 严重程度 |
|---|---|---|
| **7 天不活动会被暂停** | 项目进入 paused 状态，打不开，要去后台点 Resume 恢复 | ⚠️ 中 |
| 国内访问延迟 150～300ms | 打开页面时等一下，之后是本地操作，不卡 | 轻微 |
| 偶尔连不上 | 国外服务，网络波动 | 轻微 |
| 只有 2 个免费项目 | 同时给两个客户做就要第三个账号 | 轻微 |

**关于暂停**：官方说明是"过去一周数据库活动太少"。正常营业每天开单，活动量远超要求，不会被暂停。真正会踩坑的是**连续一周完全没用**——比如放假。恢复只要去后台点一下 "Resume project"，数据都在。

### 适合谁

不想花一分钱、能接受偶尔要"点一下恢复"、数据量不大。

## 方案 B：租一台最便宜的云主机（¥68～99 / 年）

### 是什么

在腾讯云/阿里云买一台最低配的服务器（2核2G），把我们现成的 `server.js` 扔上去跑。相当于把"NAS 那台机器"搬到云上，你**不用管任何硬件、不用管任何穿透**。

### 价格（2026 年 2 月新用户活动，以官网为准）

| 配置 | 价格 | 说明 |
|---|---|---|
| 2核2G / 3Mbps / 40G SSD / 200G 月流量 | **¥68 / 年** | 最省，够用 |
| 2核2G / 4Mbps / 50G SSD / 300G 月流量 | **¥99 / 年** | 带宽多一点，推荐 |

⚠️ 这是**新用户首年价**，续费会回到 ¥480～576/年。第二年嫌贵就换一家厂商重新买（数据是一个 JSON 文件，搬走只要 1 分钟）。

### 怎么搭（30 分钟）

1. 买服务器，系统选 **Ubuntu 22.04**
2. 安全组里放行 **8080** 端口
3. 把 `server.js` + `web/` 传上去（我给的脚本可以一条命令搞定）
4. 跑起来，访问 `http://服务器IP:8080`

### 优点

| 点 | 说明 |
|---|---|
| **最稳** | 固定 IP、24 小时在线、数据在国内、延迟 20～40ms |
| **最省事** | 客户不用装 App、不用装 Tailscale、不用记 100.x 地址，一个网址打开就行 |
| **不依赖任何人的设备** | 你的电脑、客户的电脑、NAS 全关着都没事 |
| **可控** | 密码、备份、日志全在自己手里，每天自动留一份 |
| **可搬走** | 数据就是一个 JSON 文件，换服务器 1 分钟 |

### 缺点

| 问题 | 说明 |
|---|---|
| 要花钱 | ¥68 / 年起，第二年可能涨价 |
| 要备案吗 | **不绑域名、用 `IP:8080` 访问，通常不需要备案**；一旦绑域名走 80/443，就必须备案 |
| 有被扫描的风险 | 公网 IP 会被扫，但我们的服务有密码 + 8 次错误锁 IP，影响不大 |

### 适合谁

**认真交付给别人、要长期稳定、不想折腾。** 这是我最推荐的方案。

## 方案 C：用一台旧机器当服务器（0 元）

### 是什么

店里闲置的旧笔记本、迷你主机、电视盒子（N1）、树莓派，插上电插上网线，装 Node，跑 `server.js`。
外网访问需要配 Tailscale（免费）或 cloudflared 隧道。

### 优点

- 硬件不花钱
- 数据完全在自己手里，物理上就在店里
- 性能比 NAS 还强

### 缺点

| 问题 | 说明 |
|---|---|
| **还是需要一台机器常开** | 本质和 NAS 方案一样，只是把 NAS 换成旧电脑 |
| 旧电脑不稳 | 硬盘老化、突然断电、系统更新重启 |
| 要自己做外网穿透 | Tailscale 或 cloudflared，多一层配置 |
| 功耗 | 旧笔记本 15～40W，一年电费约 ¥50～130，其实不比买云主机便宜 |

### 适合谁

店里正好有闲置设备、且愿意折腾。

> 换句话说：**这条路没解决你原本的困扰**——还是得有一台机器一直开着。

## 方案 D：Cloudflare Workers + D1（0 元，但有门槛）

### 是什么

用 Cloudflare 的免费 Serverless 跑一个接口，数据存它的 D1 数据库。

### 免费额度（以官网为准）

- Workers：每天 10 万次请求
- D1：5 GB 存储

### 为什么排最后

| 问题 | 说明 |
|---|---|
| **要写代码** | 现成的 `server.js` 不能直接用，得改写成 Worker 格式（我能写，但这是额外工作量） |
| **`*.workers.dev` 在国内常打不开** | 必须绑自己的域名才稳，域名又是 ¥60+/年 |
| 排查困难 | 出问题只能看 Cloudflare 日志，客户那边帮不上手 |

### 适合谁

你自己有域名、喜欢折腾、想学 Serverless。**不适合交付给不懂技术的客户。**

---

## 方案 E：干脆不要服务器（兜底）

单文件版 + 手工"导出 → 微信传 → 导入"。

- 0 成本、0 风险、绝不冲突
- 但每次换设备都要倒一次，两台同时改就会互相覆盖

**只有一种情况值得选**：一天只在一台设备上开单，另一台只是偶尔看看。

## 我的建议

### 如果这套东西是**给别人用**（客户、朋友）

**选 B，云主机。**

理由很直接：客户不会为了一个进销存去学 Tailscale、不会去记 100.x 地址、更不会接受"每周要登录后台点一下恢复"。你给他一个网址 `http://IP:8080`，他打开就能开单——这才叫交付。

¥68 一年，摊到每天两毛钱。你收不收这个钱另说，但**这 ¥68 买的是你未来一年不用被叫去处理"打不开"**。

### 如果是**你自己店里用**

**A 或 B 都行。**

- 每天都有单子、想省这 ¥68 → Supabase，记得放假前打开一次（或者手机上看一眼也算活动）
- 不想有任何意外 → 云主机

### 如果客户已经有 NAS（比如现在这个）

用 NAS + Tailscale，也就是现在这套。不要为了省事把已有的设备废掉。

---

## 三个必须先想清楚的问题

**① 备案**
不绑域名、用 `http://IP:8080` 访问，通常不用备案。一旦你给客户一个好看的域名，就必须走备案流程（10～20 天，要营业执照或身份证）。**所以第一版建议就用 IP**，丑一点但立刻能用。

**② 续费涨价**
¥68 是首年新用户价，第二年 ¥480+。到时候把数据导出来（一个 JSON），换一家厂商重新买首年优惠即可，全程 10 分钟。

**③ 数据归属**
不管选哪个，都要保证"能一键导出全部数据"。我们的服务端每天自动留一份备份（`data/bk/YYYY-MM-DD.json`），客户自己也应该每月点一次「导出」。**这一条比省钱重要。**
